# 河切训练模式设计文档

## 目标

为杭州麻将训练器新增"河切"训练模式，让玩家学会根据牌河（各家弃牌）做出攻守兼备的决策。

## 背景：杭州麻将的防守特点

杭州麻将默认**只能自摸胡**（不能点炮），因此防守的核心不是"避免放铳"，而是：

1. **不喂对手吃碰** — 打出的牌被对手吃/碰会加速对手凑牌
2. **承包风险** — 你喂了对手3次吃/碰/杠（三摊承包），对手胡了你全赔
3. **花色推测** — 从牌河推断对手在做什么花色
4. **速度判断** — 判断对手离胡多远，决定攻守
5. **三连庄点炮** — 庄家连庄3次后才能点炮胡，此时需要避免放铳

## 方案：反向构造法

从训练目标出发反向构造场景：先定好对手在听什么牌、走什么路线，再推导出合理的牌河和用户手牌。

优点：能精确控制每道题教什么概念，保证训练价值，实现复杂度适中。

## 第一批交付：攻守弃牌 + 安全判断

### 题型1：攻守弃牌

给用户14张手牌 + 对手牌河 + 明牌，选一张打出去。与"何切"的区别：需要综合考虑牌效（进攻）和喂牌/承包风险（防守）。

**评分公式**：
```
综合得分 = 牌效得分 × 进攻权重 - 危险度 × 防守权重

权重动态调整：
- 我接近听牌 → 进攻权重高
- 对手疑似听牌 → 防守权重高
- 已喂2摊 → 防守权重暴增
```

**训练子概念**：
- 花色回避（对手做清一色）
- 承包陷阱（已喂2摊的危险局面）
- 攻守平衡（我快听 vs 对手也快）
- 财神牌取舍

### 题型2：安全判断

给一张"候选弃牌" + 对手牌河 + 明牌，判断安全等级。

**选项**：安全🟢 / 注意🟡 / 危险🔴

**判断依据**：
1. 对手自己打过的牌 → 安全
2. 花色判断 → 对手大量弃某花色 → 该花色安全
3. 壁牌(kabe) → 某牌4张都能看到 → 相关顺子不存在
4. 对手明牌花色 → 该花色危险
5. 承包预警 → 已喂2摊时任何相关牌都高危

## 数据模型

```javascript
{
  myHand: [0,1,2,...],           // 我的手牌（14张）
  rivers: [                      // 各家牌河（按出牌顺序）
    [5, 27, 31, 8, ...],        // 下家
    [28, 6, 0, 17, ...],        // 对家
    [29, 30, 7, 15, ...]         // 上家
  ],
  openMelds: [                   // 各家明牌（吃碰杠）
    [{type:'chi', tiles:[3,4,5]}],
    [],
    [{type:'pon', tiles:[31,31,31]}]
  ],
  myFeeds: [0, 1, 0],           // 我喂了各家几摊
  opponentHands: [...],          // 对手真实手牌（隐藏，用于答案判断）
  opponentWaits: [...],          // 对手听什么（隐藏）
  questionType: 'discard'|'safety',
  turnNumber: 8
}
```

## 场景生成引擎（反向构造法）

### 流程

1. **选训练概念** — 从题型对应的子概念池中随机抽取
2. **构造对手手牌** — 根据概念生成对手牌面（如做清一色筒子的手牌）
3. **推导对手牌河** — 按"字牌→端张→中张"的合理顺序生成牌河
4. **构造用户手牌** — 确保存在攻守两难选择（一张牌效好但危险，一张安全但慢）
5. **质量验证** — 确保最优解和次优解有明显差异

### 牌河生成规则

- 正常路线：先打孤张字牌 → 再打边张(1/9) → 最后打中张(4/5/6)
- 清一色路线：先打其他两个花色 → 再打风牌字牌
- 牌河长度根据巡目决定（入门6-8张，进阶8-12张，高级10-15张）

### 安全等级映射

- 0-30: 安全🟢
- 31-60: 注意🟡
- 61-100: 危险🔴

## 解析系统

延续何切的"大白话"风格：

**攻守弃牌解析**：
> "打5筒虽然让你少接4张有用牌，但下家已经碰了两组筒子，牌河里一张筒子都没有，他大概率在做筒子清一色。你已经帮他碰过一次了，再喂一张就三摊承包了！打东风安全得多，虽然慢一步，但不会被包。"

**安全判断解析**：
> "这张5筒非常危险。原因：(1) 下家的牌河全是万字和条子，没有一张筒子，他可能在做筒子；(2) 下家已经碰了两组筒子，确认在做筒子；(3) 5筒是中张，能和很多筒子搭配，被吃碰概率高。"
